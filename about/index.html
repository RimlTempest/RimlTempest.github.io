私について

riml / 髙橋 大貴

Web のフロントエンドを書いています。

最近はデザインシステム（riml-ds）と、その上に載るプロダクトを作っています。

リズムゲームと、絵と、細かい UI の話が好きです。

いま作っているもの

ひとつの見た目の基準を決めて、その上にプロダクトを並べていく、ということをしています。

riml-ds
トークン（W3C DTCG）と Lit の Web Components でできたデザインシステム。React / Vue / Svelte / Astro 向けのラッパーは Custom Elements Manifest から生成します。
qrcc
QR・バーコードの生成と読み取り、管理、印刷。TanStack Start と Rust（workers-rs）を Cloudflare Workers に載せています。
noter
簡易ノートアプリ。riml-ds の部品を最初に試す場所になっています。

好きなもの

画面の外のこと。

リズムゲーム
CHUNITHM と maimai は虹レートまで。第 2 回ガルパ杯は二次予選（仙台）に出ました。BeatTube はプレイヤーランキング最大 5 位。

VTuber の配信とアニメ。『転生したらスライムだった件』が一番好きです。
つくること
Connect2019 優秀賞、校内ハッカソンで最優秀賞と企業賞をもらいました。

全身 5 方向

正面・横・背面・斜め前・斜め後ろ。横に流して見られます。

  • 正面
  • 横
  • 背面
  • 斜め前
  • 斜め後ろ

顔のアップ

正面・横顔・斜め 45 度。

  • 正面
  • 横顔
  • 斜め 45 度

表情

通常・微笑み・喜び・真剣・驚き・困り顔の 6 種。

  • 通常
  • 微笑み
  • 喜び
  • 真剣
  • 驚き
  • 困り顔

髪型

前髪・横髪・後ろ髪・髪飾り。

  • 前髪
  • 横髪（左側）
  • 後ろ髪
  • 髪飾り後ろの襟元に「×」の飾りがある

衣装・小物

セーラージャケットと、その周りのもの。

  • 上着（前面）セーラージャケット
  • 上着（背面）襟の背面に「×」
  • インナーノースリーブのハイネック
  • ボトムススカート + ショートパンツ
  • ソックス・ガーター右太ももにガーター
  • シューズ厚底のスニーカー
  • ネクタイセーラーのリボン
  • 装飾・タグサイドのストラップとタグ
  • その他の装飾腕のポケットとベルト
